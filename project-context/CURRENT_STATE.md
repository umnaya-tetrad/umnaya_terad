# Текущий этап проекта

Срез 19.11.2026. **Application реализуется в локальной work/application. Фронтенд и HTTP-адаптеры проверены на контрактных данных. Совместный запуск пилота ожидает домен и worker processing.**

## Что строим

Мобильное веб-приложение для учителей обычных школ: реальное ДЗ по алгебре 7–9, готовые личные аккаунты, проверки с названием и условные тетради без ФИО. Учитель снимает страницу с одной/несколькими задачами; продолжение добавляет к тому же комплекту до отправки. Один запрос checker по комплекту, серверный фон и сохранение. Готовые задачи показываются по готовности, отзыв относится к каждой выделенной задаче отдельно.

Завершение всей проверки двухэтапное: ожидание обработки/просмотр и оценки с доступным редактированием → окончательное согласие фиксирует состав и создает отдельный LLM-запрос аналитики. Итог и материалы сохраняются в истории. Основания — R01–R86 в [DECISIONS](pilot/DECISIONS.md); требования — [PRODUCT](pilot/PRODUCT.md).
