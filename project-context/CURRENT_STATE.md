# Текущий этап проекта

Срез 18.11.2026. Поддерживать этот файл после существенных проверенных изменений, используя smartnote-doc-sync. Это первый документ для нового агента после корневого AGENTS.md.

## Что разрабатываем

Пилот мобильного веб-приложения для учителей обычных школ: самостоятельная проверка настоящего ДЗ класса по алгебре 7–9. Именованная проверка, условные тетради без ФИО, фото задач, разбор до первой ошибки и сводка по подтверждениям. Полные правила — [PRODUCT.md](pilot/PRODUCT.md).

## Что подготовлено

- Согласована спецификация 1.0 по решениям R01–R79; основной поток не требует нового опроса владельца о базовых функциях.
- Подготовлены архитектурные решения T01–T09, этапы P01–P09 и будущая приемка A01–A25.
- Подготовлен небольшой внутренний текстовый математический набор и дополнение к промпту; это не новый модельный прогон.
- Объединены контекст, исследования и снимки исходных материалов. В этом репозитории код приложений пока отсутствует.
- Подготовлены три проектных skills: вход в контекст, синхронизация документации и preflight перед push/merge. Их триггеры закреплены в корневом AGENTS.md; отдельного доступа к чату автора не требуется.
- Подготовлены проверка структуры/ссылок и workflow GitHub Actions. Локальная проверка и независимый вход агента с пустым контекстом прошли; результат удаленного CI нужно смотреть в Actions, а не предполагать по наличию workflow.

## Что еще не сделано

Рабочий пилот по спецификации не реализован и не развернут. Нет нового сквозного API-прогона, подтверждения скорости 5–15 секунд, измерения качества по реальному ДЗ или проведенной самостоятельной апробации. Публичный лендинг не заменен в рамках подготовки документации. Снимок кода показывает задел одиночного фото, а HTML — демонстрацию.

Следующая работа — P01 из [IMPLEMENTATION_PLAN.md](pilot/IMPLEMENTATION_PLAN.md): получить и осмотреть код, воспроизвести исходные проверки, сверить существующий сервер/домен и перейти к личному доступу, данным и долговечной очереди. Техническая основа — SmartNoteLanding, визуальная — product-kit. [Источники и ревизии](SOURCES.md).

## Важные ограничения

Ядро Gemini через Polza, CAS отдельно. Несколько учителей одновременно, ориентир 30 тетрадей по 3–5 задач; учительских квот нет. Бюджетный ориентир 400 ₽/месяц с серверным контролем средств и пополнением командой. Один автоповтор временного технического сбоя. Закрытый просмотр команды обязателен, аналитического дашборда нет. Удаление с подтверждением без корзины. Нет офлайна/push, экспорта, оценок, регистрации, чата и отдельного фото условия.

## Организационный статус

Пятничная встреча подтверждена, самостоятельная апробация планируется с понедельника; по календарю обсуждения это 20/23 ноября 2026 года, числовые даты раскрыты из относительных слов пользователя. Проведенное событие нужно записать только после факта. Фиксированного конца апробации нет; доступ/материалы сохраняются, автоматического удаления пока нет.

Первый успех — самостоятельная проверка реального ДЗ и полезный разбор, без доказанной экономии времени. Поддержка через мессенджер по возможности в течение дня. Формат письменного итога еще не выбран. Устная инструкция — без конфиденциальных данных и ФИО; школьное обсуждение внешней обработки пока отложено. Подробные границы — [QUESTIONS.md](pilot/QUESTIONS.md).
