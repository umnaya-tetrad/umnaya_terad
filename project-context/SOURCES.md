## Исходный код для реализации

Исходники приложений не копируются в эту папку документации. Ссылки на отсутствующие здесь файлы кода переведены в GitHub blob/tree URL с закрепленными commit SHA. Чтобы изменять код, получить соответствующий upstream-репозиторий, проверить его актуальный статус и локальные инструкции. Выбор более новой ревизии документировать с отличиями; не объявлять старый снимок сегодняшним состоянием.

Техническое направление T01 — развивать рабочий пилот на базе SmartNoteLanding и адаптировать дизайн product-kit. Это план, не уже перенесенный код. Размещение выбрано на существующих сервере/домене, но доступы, ресурсы и развертывание не входят в этот документационный комплект.

## Происхождение и изменения ссылок

[IMPORT_MANIFEST.json](IMPORT_MANIFEST.json) содержит исходные относительные пути, SHA-256 оригиналов, SHA-256 первоначальной публикации и upstream-ревизии. При переносе Markdown-ссылки адаптированы к местным файлам либо закрепленным URL. Первые файлы входа дополнены для нового репозитория; старые машинные пути не являются инструкцией коллеге.

Хеши публикации описывают этот начальный импорт, а не запрет дальнейшей правки рабочей спецификации. Последующие изменения отслеживаются Git и smartnote-doc-sync. Снимки references/архивы не обновлять молча; при новой сверке записывать источник и ревизию.
