# Решения владельца продукта: учительский пилот

Версия 1.1 · 19.11.2026. Ниже сохранены согласованные решения R01–R86 с источниками. Более позднее уточнение имеет приоритет над прежней формулировкой; текущий цельный результат изложен в [PRODUCT.md](PRODUCT.md).

Это решения о требованиях, а не доказательство реализованных функций или проведенной апробации. Архитектурные решения разработчика T01–T10 выделены отдельно в [TECHNICAL_PLAN.md](TECHNICAL_PLAN.md).
