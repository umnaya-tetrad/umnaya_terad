# Продукт и границы пилота

Спецификация 1.0 · 18.11.2026. Согласованные требования R01–R79 находятся в [DECISIONS.md](DECISIONS.md). Это описание будущего пилота, не отчет о его реализации.

## Ценность и критерий первого результата

Учитель математики обычной школы проверяет настоящее ДЗ всего класса по алгебре 7–9. Приложение дает предварительный разбор рукописного решения, помогает найти первую ошибку и увидеть повторяющиеся математические правила в сводке. Учитель сверяет результат и переносит замечания в бумажную тетрадь; итог по учебной работе остается за ним.

Первый достаточный результат — самостоятельная проверка ДЗ и полезный разбор. Доказанная экономия времени пока не обязательна. Фактическое использование и время собираются автоматически и приблизительно, без дополнительных кнопок; ручной контрольный замер только необязательное организационное предложение.

Конкретные темы реальных ДЗ пока неизвестны. Собственные примеры нужны для разработки и не подменяют работы учителей. Целевая рамка 7–9 классов не доказывает уже проверенное качество по всей программе.

## Участники и единицы работы

| Понятие | Значение |
|---|---|
| Учитель | Личный аккаунт, выданный командой; видит свои проверки |
| Проверка | Именованный комплект для одного ДЗ; не требует предварительно создавать класс/тему |
| Тетрадь | Условная работа одного ученика внутри проверки, например «Тетрадь 1»; без ФИО и постоянного профиля человека |
| Задача | Одно математическое решение внутри тетради; максимум одна первая найденная ошибка |
| Фото/страница | Один упорядоченный фрагмент этой задачи. На фото не должно быть разных задач |
| Версия входа | Конкретный набор фото задачи; замена создает новую версию |
| Разбор | Неизменяемый результат системы для конкретного входа/попытки |
| Отзыв учителя | Согласие или сообщение об ошибке ИИ, плюс необязательный комментарий; отдельно от математического вывода |
| Команда | Закрытый просмотр материалов для поддержки и анализа, с отдельными полномочиями и аудитом |

Разные варианты проверяются независимо, без выбора «Вариант 1/2», общего справочника заданий или сравнения одинаковых номеров. Проверяем только загруженные решения: приложение не сверяет весь список заданных номеров и не ищет несданные задания.

## Основной поток

1. Учитель входит в готовый аккаунт и создает «Новую проверку» с названием.
2. Открывает условную тетрадь, держит соответствующую бумажную работу перед собой.
3. Добавляет задачу камерой или из галереи. Для длинного решения объединяет несколько фото в одну задачу; порядок сохраняется. Есть предпросмотр и пересъемка.
4. Завершенная группа фото задачи отправляется на сервер, пока учитель снимает следующую задачу этой тетради. Сначала он доснимает всю тетрадь.
5. После съемки смотрит готовые результаты по одному в порядке готовности. Не нужно ждать первую снятую задачу или весь комплект.
6. Сверяет разбор с увеличиваемым фото, переносит замечания на бумагу, оценивает именно работу ИИ.
7. Переходит к следующей тетради или возвращается позже. Сводка доступна по мере подтверждения, без кнопки завершения проверки.

Детальные переходы и состояния: [TEACHER_FLOW.md](TEACHER_FLOW.md).

## Входные материалы и разбор

Принимаются фотографии, без PDF/документов. Камера и галерея обязательны. Встроенного редактора обрезки/ручного поворота нет; технический учет ориентации камеры не является отдельной пользовательской функцией. Фото можно увеличивать при просмотре.

Условие должно быть достаточно представлено на снимках самой задачи: уравнение, выражение или запись «дано/найти». Отдельное фото учебника/условия в первом пилоте отложено. Несколько фото самого решения поддерживаются. При нехватке условия, нечитаемом фрагменте или неподдерживаемом случае система сообщает ограничение, не придумывает недостающее и не записывает технический отказ как ошибку ученика.

Для успешно разобранной задачи показываются:

- исходные фото с увеличением;
- распознанные математические шаги;
- первая найденная ошибка: ошибочный шаг, тип, математическое правило, короткое объяснение и правильная запись именно этого шага;
- отдельная отметка незавершенности, если она установлена.

Анализ идет до первой ошибки, а не по всем последующим ошибкам. Полное эталонное решение не требуется. Корректные написанные шаги не означают завершенную задачу. Незавершенность не увеличивает число математических ошибок. Возможная описка — только предположение в разборе, без диагноза невнимательности и отдельного типа в топе.

## Оценка системы и сводка

На карточке результатов: зеленая кнопка с галочкой «Согласен с проверкой» и красная «Ошибка в проверке ИИ». Подписи и пояснение должны однозначно относиться к системе. Согласие с найденной ошибкой ученика не означает, что его решение верное.

Красная отметка сохраняет отзыв и необязательный комментарий. Она не исправляет вывод, не запускает модель повторно и не выключает сервис. Редактора OCR/формул/математического вывода нет. Просмотр карточки, переход дальше и выход не создают согласия автоматически.

В математическую сводку входят только актуальные подтвержденные разборы. Сводка показывает тетради с ошибками/без, среднее число первых ошибок по полностью подтвержденным непустым тетрадям и топ-3 типов по математическим правилам без конкретного задания. Частичные, спорные и неудачные показываются отдельно. Точные формулы, знаменатели и последствия изменений определены в [SUMMARY_METRICS.md](SUMMARY_METRICS.md).

## Возврат и изменения

Фото, анализы, отметки/комментарии сохраняются на сервере. После закрытия и на другом устройстве под тем же аккаунтом доступно актуальное состояние. Принятые сервером задачи продолжают обрабатываться без открытого приложения; еще не переданный файл принятым не считается.

Учитель может позже добавлять задачи в тетрадь и тетради в проверку. Подтверждения остальных задач сохраняются. Новая неподтвержденная задача делает ранее полностью подтвержденную тетрадь частичной, пока новый разбор не подтвержден.

Отметку и комментарий можно менять. Фото можно заменить и проверить заново: новый разбор не наследует старое согласие, поздний ответ прежней попытки не становится текущим. Прежний вывод и отзыв относятся к прежней версии, а не перезаписывают новый.

Задачу, тетрадь и всю проверку можно удалить с подтверждением. Они исключаются из активного состава и сводки; тетрадь/проверка удаляются вместе с дочерними сущностями. Корзины и восстановления в интерфейсе нет. Физическая очистка оригиналов/аудита этим решением не определена.

## Ограничения первой версии

| Область | Согласованная граница |
|---|---|
| Доставка | Веб по ссылке, Android/iPhone, основной UX на телефоне, без обязательной установки |
| Связь | Интернет, без офлайна и push; продолжение на компьютере/другом телефоне возможно |
| Нагрузка | Несколько учителей одновременно; ориентир до 30 тетрадей по 3–5 задач. Это не квота |
| Скорость | Цель 5–15 секунд на задачу; фактическая скорость еще не измерена, 15 секунд не порог автоматического отказа |
| Ядро | Gemini через Polza; CAS отдельно, без подключения в пилот |
| Неудача | Один автоповтор временного технического сбоя; затем можно пропустить, переснять или повторить позже |
| Срок/хранение | Без фиксированного окончания; доступ и материалы сохраняем после апробации, автоматического удаления пока нет |
| Команда | Закрытый раздел просмотра материалов, подробные логи без аналитического дашборда |
| Поддержка | Мессенджер; команда отвечает по возможности в течение дня, без фиксированных часов. Приостановка вручную |
| Размещение | Пилот заменит лендинг на существующих сервере и домене |
| Расходы | Ориентир 400 ₽/месяц; нет учительских квот/тарифных счетчиков. Команда контролирует средства и пополняет баланс |

В продукт не входят учебные оценки/баллы, экспорт, самостоятельный ученический режим, платежи, обязательная иерархия класса/темы, редактор вывода, подсветка строк поверх фото, чат поддержки и отдельное фото условия. Письменный итог апробации — организационный документ команды с пока не выбранным форматом, не функция экспорта.
