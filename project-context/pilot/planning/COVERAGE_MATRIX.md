Тесты модели по умолчанию используют подставной transport; отдельный разрешенный live smoke и его расход документируются отдельно.

Проверка локальной сборки к 21:00 не закрывает будущий серверный выпуск, публичный HTTPS, реальную приемку на Android/iPhone, если использована только эмуляция, и самостоятельную апробацию учителем. Эти пункты передаются следующему этапу явно, без ложного PASS.
