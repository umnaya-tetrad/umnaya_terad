# Реализация локальной версии: вход для команды

19.11.2026. Общий пакет v1 подготовлен и прошел [независимое ревью](shared/SHARED_REVIEW.md). Код пилотного приложения еще предстоит реализовать; frozen checker и переносимый reference adapter уже существуют отдельно.

1. Прочитать [shared/README.md](shared/README.md) и выполнить общий офлайн gate. Здесь точные API/DTO, типы, примеры, мобильный UX, модули, проверки и передача.
2. Выбрать свое направление: [application](application/README.md), [processing](processing/README.md), [release](release/README.md). В каждой папке TASKS.md, ACCEPTANCE.md и HANDOFF.md; текущее состояние работы не выводится из наличия ТЗ.
3. Требования A01–A25 распределены в [матрице](COVERAGE_MATRIX.md). Формат задач — [TASK_FORMAT.md](TASK_FORMAT.md). Результаты финального перекрестного ревью — [TASK_REVIEW.md](TASK_REVIEW.md).

Ранние [TEAM_SPLIT_DRAFT.md](TEAM_SPLIT_DRAFT.md), [CONTRACT_DRAFT.md](CONTRACT_DRAFT.md) и [REVIEW_NOTES.md](REVIEW_NOTES.md) сохраняют происхождение обсуждения, но не переопределяют shared v1 и подробные ТЗ. Новые личные характеристики, причины доступности и распределение по именам в документы не включаются.

Цель — локальная сборка через Docker Compose к 21:00. Полный пакет обработки/аналитики готовится к 17:00 и передается до 18:00. Bootstrap/shared-config владелец application до передачи B4; интегратор release после B4 отвечает за слияние и устранение блокирующих дефектов в любом модуле по общему контракту. Внешний выпуск и реальная учительская апробация имеют отдельную приемку.
