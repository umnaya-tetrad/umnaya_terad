## Остальная работа без нового опроса

| Категория | Оставшаяся работа | Влияние |
|---|---|---|
| Факты окружения | Конфигурация/ресурсы сервера, HTTPS, хранилище/бэкапы, доступы без вывода секретов | Проверить при разработке до развертывания; не считать уже готовыми |
| Модель | Доступность выбранного подключения, несколько фото, новый контракт, usage/баланс/цена | Проверить адаптер и реальные условия интеграции; не подменять прошлым benchmark |
| Совместимость/скорость | Реальные фото Android/iPhone, ориентация, очередь, несколько аккаунтов, полный интервал 5–15 секунд | Измерить; цель не является SLA или таймаутом |
| Организация | Конкретные участники, контакт мессенджера, фактические темы и пик нагрузки | Уточняются по организации запуска, не новые обязательные поля приложения |
| Письменный итог | Формат, адресат, автор/подписант и содержание | Отложено владельцем; не блокирует основной продукт |
| Отложенные границы данных | Физическое стирание/отдельный запрос на удаление/аккаунт; отдельный датасет/публикация/обучение | Не считать реализованными или автоматически разрешенными; текущую политику не расширять |
| Школьное обсуждение внешней обработки | Не проводилось и отложено пользователем | Устная инструкция R67 — установленный факт, не полученное согласие школы |
