# Учительский пилот SmartNote

Спецификация 1.0 · 18.11.2026. Требования согласованы по решениям R01–R79. Приложение по этой спецификации еще не реализовано и не развернуто.

## Что собираем

Мобильное веб-приложение для учителей обычных школ: проверить настоящее ДЗ класса по алгебре 7–9, сверить разбор с тетрадью, отметить качество проверки ИИ и увидеть сводку математических ошибок. Вход по готовому личному аккаунту, без регистрации. Основной сценарий — телефон Android/iPhone; продолжение на другом устройстве поддерживается.

Поток: **Новая проверка с названием → условная тетрадь без ФИО → съемка задач с обработкой в фоне → готовые разборы в порядке готовности → согласие/ошибка ИИ → следующая тетрадь → обновляемая сводка.**

На фото одна задача; у задачи может быть несколько упорядоченных фото. Сначала снимаем все задачи тетради, затем смотрим результаты. Работаем с интернетом, без офлайна и push. Отдельное фото условия отложено.

## Что зафиксировано

| Область | Решение |
|---|---|
| Проверка | До первой математической ошибки; шаг, тип, правило, объяснение и правильная запись этого шага. Незавершенность отдельно |
| Контроль учителя | Зеленое «✓ Согласен с проверкой», красное «Ошибка в проверке ИИ»; необязательный комментарий, без редактора вывода |
| Фото и оформление | Камера/галерея, предпросмотр/пересъемка, увеличение; без PDF, обрезки, ручного поворота и подсветки на фото. Клетчатый стиль и цвета product-kit |
| Сводка | Подтвержденные результаты; работы с ошибками/без, среднее по полностью подтвержденным непустым тетрадям, топ-3 математических правил; частичные/спорные отдельно |
| Изменения | Добавлять задачи/тетради позже; менять отзыв/комментарий; заменять фото с повтором и снятием прежнего согласия; удалять задачу/тетрадь/проверку с подтверждением, без корзины |
| Сохранение | Серверная обработка после закрытия; фото, разборы, отзывы и журналы сохраняются. Конца апробации и автоматического удаления пока нет |
| Ядро | Gemini через Polza; CAS развивается отдельно. Один автоповтор временного технического сбоя, затем ручное действие |
| Команда | Закрытый раздел просмотра проверок и материалов с аудитом. Подробные логи, без дашборда |
| Размещение/расходы | Существующие сервер и домен, пилот заменяет лендинг. Ориентир 400 ₽/месяц; учительских квот нет, серверный контроль средств и пополнение командой |
| Поддержка | Мессенджер, отвечает команда по возможности в течение дня, без фиксированных часов. Приостановка вручную, не по числу красных отметок |

Рабочий объем — несколько одновременно работающих учителей, до 30 тетрадей по 3–5 задач в проверке. Это ориентир нагрузки, не пользовательский лимит. Цель ожидания одной задачи — 5–15 секунд, еще без измеренного подтверждения.

Пятничная демо-встреча подтверждена; полноценная апробация начинается с понедельника. По календарю обсуждения это 20 и 23 ноября 2026 года; числовые даты раскрыты из относительных слов пользователя. Для первого успеха достаточно самостоятельной проверки ДЗ и полезного разбора, без доказанной экономии времени. Письменный итог нужен; его формат пока не выбран и функций приложения не блокирует.

## Как использовать спецификацию

Сначала прочитать PRODUCT, затем TEACHER_FLOW, SUMMARY_METRICS и технический план. Подтвержденные требования этой папки определяют текущий пилот; старые макеты и корневые планы дают контекст, но не меняют согласованный поток. Технические решения разработчика явно отделены от решений владельца.

[Карта источников](../docs/KNOWLEDGE_MAP.md) объясняет роль трех исходных систем. [Статический аудит](../docs/INTEGRATION_AUDIT.md) описывает найденный код. Изменения этой консолидации ограничены документацией. Код исходных репозиториев не менялся; API-прогоны, испытания и развертывание не выполнялись.

Проверены локальные ссылки, целостность R01–R79 и Q01–Q46, уникальность A01–A25.
