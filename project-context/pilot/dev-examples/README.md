# Собственные примеры для тестирования при разработке

Версия: 0.1, 18.11.2026. Подготовлено по решению R33 в [DECISIONS.md](../DECISIONS.md).

Уточнение R66: набор и математические разборы сверяет сама команда; это небольшая внутренняя валидация разработки. Для нее не нужны отдельный пользовательский процесс, экспертный кабинет или обязательное привлечение учителя. Настоящие фото/модельные прогоны и их результаты отмечаются только после фактического выполнения.

Это собственный текстовый стартовый набор по характерным темам алгебры 7–9. Он предназначен только для разработки и проверки поведения. Учителя на апробации загружают свои реальные домашние работы; набор не ограничивает их содержание и не заменяет школьную апробацию.

Здесь нет реальных школьных данных, сторонних изображений или результатов модельного прогона. Рукописные/фото-версии пока не созданы: текстовые решения не проверяют качество распознавания почерка. Перечень не является полным покрытием программы или заявлением о поддержке всех задач.

## Правила эталона

- Условие записано отдельно, шаги решения нумеруются с 1. Указан первый неверный шаг; более поздние строки сохраняются во входе специально для проверки остановки выдачи.
- При первой ошибке ожидаются ее тип, понятное правило и правильная запись этого шага для учителя. Полное эталонное решение не является требуемой выдачей.
- Для корректных завершенных и незавершенных решений даны отдельные случаи. В ошибочных цепочках полнота отдельно не размечена в версии 0.1: основной оракул здесь относится к первой ошибке.
- Это ручной математический оракул на собственных простых примерах, а не независимое исследование точности. Перед модельной регрессией зафиксировать версию входных изображений/промпта/контракта и не менять ожидаемое под ответ модели.
- При автоматизации сравнивать математический смысл, не только строку: порядок корней в DEV12 и эквивалентные формы правильного шага могут различаться.

## Случаи

| ID | Условие | Записанные учеником шаги | Ожидаемый результат |
|---|---|---|---|
| DEV01 | Решить `2x + 5 = 13` | 1. `2x = 8`; 2. `x = 4` | Все шаги корректны, решение завершено |
| DEV02 | Решить `2x + 5 = 13` | 1. `2x = 13 + 5`; 2. `2x = 18`; 3. `x = 9` | Первая ошибка на шаге 1: знак при переносе. Правило: вычесть 5 из обеих частей. Правильный шаг: `2x = 13 - 5`. Не возвращать шаги 2–3 |
| DEV03 | Решить `3(x + 2) = 15` | 1. `3x + 2 = 15`; 2. `3x = 13`; 3. `x = 13/3` | Первая ошибка на шаге 1: раскрытие скобок. Множитель относится к каждому слагаемому. Правильный шаг: `3x + 6 = 15` |
| DEV04 | Решить `x/3 - 2 = 4` | 1. `x/3 = 6`; 2. `x = 2` | Первая ошибка на шаге 2: обратная операция. Для получения x обе части умножаются на 3. Правильный шаг: `x = 18` |
| DEV05 | Упростить `(2a + 3) + (a - 5)` | 1. `2a + 3 + a - 5`; 2. `3a - 2` | Все шаги корректны, преобразование завершено |
| DEV06 | Раскрыть `(x + 3)^2` | 1. `x^2 + 9` | Первая ошибка на шаге 1: формула квадрата суммы, пропущено удвоенное произведение. Правильный шаг: `x^2 + 6x + 9` |
| DEV07 | Разложить `x^2 - 9` на множители | 1. `(x - 3)^2` | Первая ошибка на шаге 1: формула разности квадратов. Правильный шаг: `(x - 3)(x + 3)` |
| DEV08 | Решить `-2x > 6` | 1. `x > -3` | Первая ошибка на шаге 1: при делении неравенства на отрицательное число знак меняется. Правильный шаг: `x < -3` |
| DEV09 | Вычислить арифметический квадратный корень `sqrt(25)` | 1. `sqrt(25) = ±5` | Первая ошибка на шаге 1: арифметический квадратный корень неотрицателен. Правильный шаг: `sqrt(25) = 5` |
| DEV10 | Упростить `(x^2 - 1)/(x - 1)`, дано `x ≠ 1` | 1. `(x - 1)(x + 1)/(x - 1)`; 2. `x + 1, x ≠ 1` | Все шаги корректны, ограничение сохранено, преобразование завершено |
| DEV11 | Решить `x^2 - 5x + 6 = 0` | 1. `(x - 2)(x - 3) = 0`; 2. `x = 2 или x = 3` | Все шаги корректны, решение завершено |
| DEV12 | Решить `x^2 - 5x + 6 = 0` | 1. `D = (-5)^2 - 4·1·6 = 1`; 2. `x = (5 ± 1)/2`; 3. `x1 = 2, x2 = 4` | Первая ошибка на шаге 3: арифметика при вычислении корня. Правильный шаг: `x1 = 2, x2 = 3` |
| DEV13 | Решить систему `x + y = 5`, `x - y = 1` | 1. `2x = 6`; 2. `x = 3`; 3. `y = 2` | Все шаги корректны, решение завершено |
| DEV14 | Решить систему `x + y = 5`, `x - y = 1` | 1. `y = 5 - x`; 2. `x - (5 - x) = 1`; 3. `x - 5 - x = 1` | Первая ошибка на шаге 3: знак при раскрытии скобок после минуса. Правильный шаг: `x - 5 + x = 1` |
| DEV15 | Решить `3x + 6 = 15` | 1. `3x = 9` | Написанный шаг корректен, но задача не доведена до ответа. Отдельная незавершенность, не математическая ошибка этого шага |
| DEV16 | Решить `x^2 - 5x + 6 = 0` | 1. `D = (-5)^2 - 4·1·6 = 1` | Написанный шаг корректен, корни еще не найдены. Незавершенное решение |
| DEV17 | Указать ОДЗ выражения `1/(x - 2)` | 1. `ОДЗ: x ∈ R` | Первая ошибка на шаге 1: не исключено значение, обращающее знаменатель в ноль. Правильный шаг: `ОДЗ: x ≠ 2` |
| DEV18 | Указать ОДЗ выражения `1/(x - 2)` | 1. `x - 2 ≠ 0`; 2. `x ≠ 2`; 3. `ОДЗ: x ∈ (-∞; 2) ∪ (2; +∞)` | Все шаги корректны, область указана полностью |

Всего 18 примеров: 6 корректных завершенных, 10 с первой ошибкой, 2 корректных незавершенных. Первоначальные 16 случаев прошли независимую математическую сверку; DEV17/DEV18 добавлены для ОДЗ после требования R37. Это состав набора, не результаты работы модели.

## Что дополнить при создании фото-версии

- DEV14 на двух фото одной задачи: шаги 1–2 на первом, шаг 3 на втором. Ожидаем ту же первую ошибку, страницы анализируются совместно.
- Разные читабельные почерки, снимки с телефона, поворот/свет/обрезка, не меняющие математику. Условия должны попадать в согласованный вход.
- Отдельные снимки с нечитаемым существенным знаком, отсутствующим необходимым фрагментом и техническим сбоем. Эталон отказа задавать по реальному изображению; из одной текстовой таблицы он не следует.
- Не использовать эти примеры как свидетельство экономии времени, качества на всей программе, самостоятельного использования учителем или факта школьного пилота.
