## Приоритет и сохранение истории

Новые прямые ответы владельца уточняют прежние планы. Для текущего пилота согласованные PRODUCT/DECISIONS приоритетнее первоначальных исследовательских предложений и демомакетов. Технический выбор разработчика должен быть помечен отдельно и выполнять согласованный сценарий.

[Первоначальный интеграционный реестр D01–D13/O01–O09](history/DECISIONS_initial_2026-11-18.md) сохранен исторически. Его вопросы не нужно повторять без сверки с итоговым реестром: большинство уже закрыто R-решениями. Старые даты и обязательная иерархия класса/темы не переопределяют пилот.

Корень рабочей папки не является отдельным Git-репозиторием по исходному осмотру. Два исходных репозитория сохраняются раздельно; безусловной синхронизации копий документации в product-kit нет. [SOURCE_SNAPSHOT.json](SOURCE_SNAPSHOT.json) описывает исторический осмотр, а не новую runtime-проверку.
