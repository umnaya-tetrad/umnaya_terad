## Как добавлять запись

Для решения: дата → формулировка → кто/какой источник подтвердил → какие файлы/поведение меняются → как проверить → что остается открытым. Для вопроса: неизвестное → текущие основания → какое свидетельство его закроет. Если решение пересмотрено, сохранять прежнее основание и ссылку на новую запись.

Не заполнять реестр фиктивной ответственностью, встречами, метриками и предполагаемыми согласиями. История проверки исходников хранится в [аудите](../INTEGRATION_AUDIT.md), версия источников – в [срезе](../SOURCE_SNAPSHOT.json).
