# Ручная сверка математической проверки

Прогон: `smoke-20260915T214557Z-29094936`, prompt `linkage_v2`, `temperature=0`, `max_completion_tokens=4000`, конкурентность 10. В наборе 11 одностраничных `images_without_answer` из EGE Math Solutions Assessment Benchmark: задачи 13 и 15, `parts_count=1`.

По результатам этой сверки для текущего MVP зафиксирована `google/gemini-3.7-flash`. Gemini 3.1 Flash Lite остаётся в таблицах только как исторический контрольный кандидат.

## Входной фильтр

Сначала проверяется не математика всех строк, а две необходимые предпосылки: JSON проходит серверный контракт и модель не объявляет ошибочной работу с максимальным баллом. Для пяти работ с `score=2` по соглашению этой проверки отсутствие найденной ошибки считается достаточным; построчная ручная сверка для них не проводится.

| Модель | Валидный JSON | Работы с `score=2` без выдуманной ошибки | Допуск к детальной сверке |
| --- | ---: | ---: | --- |
| `google/gemini-3.1-flash-lite` | 11/11 | 0/5 | Нет |
| `google/gemini-3.7-flash` | 11/11 | 5/5 | Да |

Поэтому результаты Lite ниже диагностические: они показывают характер сбоя, но не входят в его оценку качества.
