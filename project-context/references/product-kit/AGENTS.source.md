# Работа с продуктовым комплектом SmartNote

Начните с README.md, docs/PROJECT_CONTEXT.md и docs/INTERFACE_GUIDE.md. Ноябрьский контекст имеет приоритет над октябрьской демонстрацией при описании текущего продукта. Не объявляйте демосостояния работающей ИИ-системой.

Сохраняйте исходные материалы и ручные изменения. Исследования — датированный контекст; новые сведения отделяйте от подтверждённых фактов, решений и гипотез. Не отправляйте письма школам и не публикуйте материалы без явного запроса пользователя.

Исходники интерфейса находятся в src/ui, оболочка — src/prototype.tsx, ролик — src/scenes/video-v6. Не подключайте внешние API, подписки, Figma, секреты или облачные сервисы для демонстрации. Анимации Remotion должны зависеть от кадра, не от таймеров, CSS-анимаций или случайности. Используйте доступные навыки Remotion и версии установленных пакетов.

После изменений: npm run lint, npm run build, npm run build:prototype, npm run build:offline, npm run render:smoke, npm run still:smoke. Визуально проверьте HTML, прототип и рендер. Обновите docs/STATUS.md фактическими результатами. preview/ — готовый отслеживаемый экспорт; обновляйте его вместе с исходниками. node_modules, out, кэши и секреты не коммитить.
