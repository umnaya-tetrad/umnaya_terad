# Устройство комплекта и редактирование

## Карта кода

`src/ui/AppScreen.tsx` содержит каталог screens, тип ScreenId, визуальные элементы, пример рукописной работы и состояния приложения. Компонент получает screen и необязательные свойства для названий, дат, работ, обработчиков и статусов. `cameraCapture` меняет подписи на «Снимок готов», «Сфотографировать решение» и «Переснять фото».

`src/prototype.tsx` управляет состоянием демонстрации: классами, темами, домашними работами, загруженными комплектами, выбранной работой, подтверждениями, отклонениями и ручным просмотром. Данные живут в React useState, не сохраняются после обновления страницы. Это локальная иллюстрация процесса без авторизации и сервера. «Сбросить демонстрацию» в унаследованной оболочке очищает подтверждения/отклонения и возвращает к роли; это не полный сброс созданных сущностей. Для чистого старта обновите вкладку.

`src/scenes/video-v6/ActionVideo.tsx` — временная шкала и действия ролика; `CameraCapture.tsx` — общая иллюстрация камеры. Камера принимает correct, local и click. Видеоряд задаёт момент вспышки кадрами; прототип дополнительно передаёт onCapture для перехода к просмотру. Это не доступ к камере устройства. Параметры анимации детерминированы относительно кадра.

`src/motion/video/Primitives.tsx` содержит только используемые v6 функции ease, clamp и компонент Brand. Общий video.css сохранён для оформления. `src/compositions/Screens.tsx` регистрирует исходные 26 макетов как Remotion Still; ещё два варианта камеры включены в автономный каталог. `src/Root.tsx` регистрирует v6, макеты и инфраструктурный SmokeTest. Старые монтажи не входят в комплект.

## Три способа просмотра

1. **Автономный каталог:** preview/index.html + screens/*.html. Каждый макет содержит CSS и SVG, работает без React-runtime и сервера. Кнопки внутри статических макетов не меняют экран; выбор производится меню каталога.
2. **Автономный интерактивный прототип:** preview/app.html. Встроены собранные React, JS и CSS; нет CDN, внешних импортов и запросов. Можно открыть через file:// или локальный сервер.
3. **Исходники и горячая перезагрузка:** npm ci, затем npm run dev. Vite обслуживает src/prototype.tsx. Remotion Studio открывается отдельно командой npm run studio.

`scripts/build-offline.mjs` использует локальный esbuild и серверный React-рендеринг. Реестр src/catalog-export.tsx формирует 28 HTML. Затем тот же скрипт собирает интерактивную оболочку в один IIFE со встроенными стилями и генерирует каталог, manifest.json. Каталог и прототип используют одни исходники, а не независимо нарисованные копии.

Генератор пишет только preview/ и .cache/. Он не экспортирует MP4. При изменении интерфейса запускайте npm run build:offline и коммитьте обновлённый preview/ вместе с исходниками. Для веб-сервера используется обычная Vite-сборка dist/; она не отслеживается в Git, поскольку автономная версия уже включена в репозиторий.

## Изменения и интерфейсы

Для нового состояния добавьте ID и разметку в AppScreen, переходы в оболочке, а при необходимости — регистрацию Still и сцену ролика. Не называйте состояние «реализованной бизнес-функцией» только из-за наличия разметки. Предопределённые метрики и обработчики нужно заменить при переходе к рабочему приложению.

Для замены фотографии согласованно обновите PaperWork в AppScreen и иллюстрацию в CameraCapture. Сейчас формулы набраны текстом. Реальные медиа следует хранить локально и подключать без внешних сетевых зависимостей; для Remotion — через staticFile и public/.

При работе с роликом сохраняйте frame-driven анимации: useCurrentFrame/useVideoConfig, interpolate/spring. Не добавляйте CSS transitions/keyframes, таймеры или случайность в рендер. Сценарии учителя, ученика, переходы и финал остаются отдельными Sequence. Текущий план: 0–4 роли, 4–74 учитель, 74–77 переход, 77–130 ученик, 130–135 приглашение школ.

## Источники и границы передачи

Комплект скопирован из рабочего проекта PermPresentaion и выбранной папки SmartNote. Включены актуальные продуктовые документы, research-garden с приложениями и реестрами источников, исходная конкурсная заявка и готовый MP4. Служебные файлы браузера, зависимости и кэши не включены. Ссылки на конкурсную заявку в копии продуктового описания исправлены на references/contest-project.docx.

Результаты сторонних исследований и контакты не проверялись заново при упаковке. Даты и выводы исходных материалов сохранены. Отправка писем, связывание со школами, публикация сайта и настройка production-инфраструктуры не выполнялись.
