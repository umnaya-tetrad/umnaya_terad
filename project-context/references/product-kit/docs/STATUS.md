# Статус продуктового комплекта

Дата: 18 ноября 2026 года. Комплект готовится как самостоятельная копия для передачи, без изменения исходного видеопроекта и исходных документов SmartNote.

## Что проверено

- npm ci: зависимости установлены из lock-файла.
- npm run lint: ESLint и TypeScript завершились успешно.
- npm run build: Remotion bundle собран.
- npm run build:prototype: Vite-сборка создана в dist/.
- npm run build:offline: созданы 28 самостоятельных HTML, каталог, manifest.json и интерактивный app.html со встроенными JS/CSS.
- npm run render:smoke и npm run still:smoke: успешный экспорт тестового MP4 и PNG.
- В браузере через http://127.0.0.1:5184/ проверены: кабинет ученика → камера → затвор → «Всё хорошо видно?»; просмотр работы → отклонение → появление работы №2 в списке дополнительного внимания; просмотр → подтверждение → «Работа подтверждена».
- Превью экрана сохранено в evidence/prototype.png. Каталог и JS/CSS прототипа не требуют CDN или сетевых сервисов при использовании готовых HTML.
- Дополнительно из перенесённых исходников v6 отрендерен кадр 2620: evidence/video-camera.png. Кадр визуально проверен, камера и касание соответствуют исходному видеоряду.

Репозиторий создан и загружен: https://github.com/svn-re7/smartnote-product-kit. Видимость PRIVATE, ветка main. Первый коммит 66079af успешно принят GitHub; локальный SHA и SHA origin/main совпали при проверке. Исходные папки не переносились и не удалялись.

Проверка прямого открытия file:// во встроенном браузере недоступна: политика браузера разрешает только HTTP/HTTPS. Этот запрет не обходился. Прототип проверен отдельно через обычный сервер разработки, а автономность HTML проверяется по структуре собранных файлов. Прямое открытие двойным щелчком в системном браузере не проверено.

Проверяющий скрипт scripts/verify-kit.mjs контролирует 28 макетов, локальные Markdown-ссылки, отсутствие внешних runtime-ресурсов в HTML, типовые сигнатуры секретов и ограничение 100 MB на файл. Отчёт: evidence/kit-check.json. Это ограниченная проверка, не полный аудит безопасности.

## Известные ограничения

Это визуальная демонстрация: без ИИ, настоящих фотографий, загрузки файлов, регистрации, сервера, базы данных и постоянного хранения. Общая статистика частично фиксирована; не все действия моделируют рабочее приложение. Прототип не используется для проверки математической точности. Детали и отличия оболочки от монтажа описаны в INTERFACE_GUIDE.md и IMPLEMENTATION.md.

Готовый ролик v6 перенесён без нового полного рендера; его исходная длительность 135 секунд, 1920×1080, 30fps. В комплекте оставлены воспроизводимые исходники для будущего экспорта. Тестовый SmokeTest проверяет инфраструктуру рендера, а не весь ролик.

Сохранены исходные версии зависимостей для совместимости с макетами. На дату упаковки npm audit сообщает 24 уязвимости (9 moderate, 15 high); отчёт сохранён в evidence/npm-audit.json. Исправления с обновлением пакетов не выполнялись. Комплект проверяется локально и не развёрнут как публичный или рабочий сервис. Vite также выдаёт предупреждения о будущем способе загрузки конфига и директивах use client в lucide-react; обе сборки завершились успешно.

Сведения исследований и договорённости со школами не перепроверялись при упаковке. При передаче использовать даты и статусы из PROJECT_CONTEXT.md; наличие интерфейса не означает готовности перечисленных функций.
