# Умная тетрадь — продукт, интерфейс и демонстрация

Самостоятельный комплект для передачи разработчику, дизайнеру, исследователю аудитории или участнику команды. Собран 18 ноября 2026 года из макетов и исходников демонстрационного ролика v6 и материалов SmartNote.

GitHub: [svn-re7/smartnote-product-kit](https://github.com/svn-re7/smartnote-product-kit), приватный репозиторий, основная ветка main.

**Быстрый просмотр:** скачайте репозиторий целиком и откройте [START_HERE.html](START_HERE.html) или [preview/index.html](preview/index.html) двойным щелчком. Интернет, Node.js и сервер для готовой HTML-версии не нужны. В каталоге можно выбирать экраны, открыть интерактивный прототип и посмотреть итоговый MP4.

Это демонстрационный интерфейс, а не готовая система проверки. Математика, фотографии и аналитика имитируются; пользовательские изменения хранятся только в памяти вкладки. HTML-галерея статическая; действия внутри приложения работают в [preview/app.html](preview/app.html).

## Что читать первым

1. [Актуальный контекст проекта](docs/PROJECT_CONTEXT.md) — решения и состояние по сведениям команды на 17–18 ноября. Имеет приоритет над октябрьской концепцией при описании ближайших планов.
2. [Продуктовое описание](docs/PRODUCT_DESCRIPTION.md) — подробная исходная концепция, аудитория, ценность, ограничения, гипотезы и исследовательские вопросы.
3. [Руководство по интерфейсу](docs/INTERFACE_GUIDE.md) — карта экранов, действия и объяснения продуктовой логики.
4. [Школьный процесс](docs/SCHOOL_PROCESS.md) — текущее предложение школам, встречи и возможная апробация.
5. [Архитектура и редактирование](docs/IMPLEMENTATION.md) — устройство кода, команды и ограничения прототипа.

Октябрьский видеоряд фиксирует демонстрационную версию интерфейса. Он не подтверждает фактическую готовность всех функций и не переопределяет ноябрьские продуктовые решения. Исследовательские отчёты содержат датированные выводы, требующие актуальной проверки перед практическим применением.

## Запуск и редактирование

Для разработки требуется Node.js **24.15+** и npm. Все пакеты закреплены lock-файлом; Remotion — **4.0.538**.

```sh
npm ci
npm run dev
```

Интерактивный прототип: `http://127.0.0.1:5184/`. Выберите экран в боковом меню или пройдите сценарий кнопками. В сцене камеры кнопка затвора открывает просмотр снимка; реальная камера устройства и загрузка файлов не используются.

```sh
npm run build:offline     # обновить preview/ после изменений исходников
npm run build:prototype   # собрать веб-прототип в dist/
npm run preview           # открыть dist/ через локальный сервер
npm run studio            # Remotion Studio; адрес напечатается в терминале
npm run render:video      # при необходимости заново экспортировать v6
```

Композиция ролика — `SmartNotebookV6`, 4050 кадров при 30 fps, 1920×1080, без звука для устного комментария. Готовый файл: [media/smart-notebook-v6.mp4](media/smart-notebook-v6.mp4). Новый экспорт попадает в `out/smart-notebook-v6.mp4`; включённый MP4 автоматически не перезаписывается.

## Проверка

```sh
npm run lint
npm run build
npm run build:prototype
npm run build:offline
npm run render:smoke
npm run still:smoke
node scripts/verify-kit.mjs
```

Проверенные результаты и ограничения — в [docs/STATUS.md](docs/STATUS.md). После изменения интерфейса пересоберите `preview/`, чтобы готовые HTML и исходники совпадали. При изменении видеоряда готовый MP4 нужно экспортировать отдельно.

## Передача другому агенту

Передайте ссылку на репозиторий или папку целиком. Начальная инструкция: «Прочитай README, docs/PROJECT_CONTEXT.md, docs/PRODUCT_DESCRIPTION.md и docs/INTERFACE_GUIDE.md. Не считай демонстрационные экраны доказательством готовности сервиса. Текущие решения бери из актуального контекста».

Репозиторий приватный. Доступ другому человеку или внешнему агенту предоставляется владельцем отдельно. Исходный код передаётся без объявления открытой лицензии; лицензии зависимостей сохраняются за их авторами. Материалы исследований и конкурсная заявка включены как источники контекста, а не как новая независимая проверка их утверждений.
